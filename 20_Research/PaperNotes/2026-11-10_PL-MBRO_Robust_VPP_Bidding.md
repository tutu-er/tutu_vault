# PL-MBRO: 概率层聚类标定的多界鲁棒 VPP 竞价

- **arXiv**: [2610.41633](https://arxiv.org/abs/2610.41633)
- **日期**: 2026-11-10
- **标签**: #RobustOptimization #VirtualPowerPlant #Bidding #ElectricityMarket #Clustering #MILP

---

## 1. 解决了什么问题

可再生虚拟电厂（RVPP）聚合可调度/不可调度的可再生电源、储能和柔性负荷，同时参与日前市场与二次备用市场，必须应对电价、可再生出力和负荷的多重不确定性。多界鲁棒优化（MBRO）适合这个场景——它通过多个偏差层来对冲不利实现，并把竞价问题保持为一个可解的无场景 MILP。但 MBRO 的性能强依赖两个参数的标定：**偏差界（deviation bounds）和不确定性预算（uncertainty budgets）**。现有做法普遍用固定分位数的偏差界 + 外部指定的预算向量，缺乏数据驱动、自动化的标定方法。

## 2. 核心方法解读（师兄讲解版）

先搞懂 MBRO 在干嘛。鲁棒优化要设定「不确定参数最坏能坏到什么程度」。MBRO 的聪明之处是分层：它不假设所有参数同时坏到最坏，而是设几层「坏的程度」，再用一个「预算」限制「有多少个时段/参数允许坏到最坏」。这样既对冲了风险，又不会像传统「盒子」鲁棒那样过度保守。

但问题来了：这个「坏到最坏」的界设多少？预算给多少？以前大家拍脑袋或者做灵敏度分析。本文说：**这些都应该从历史数据里自动长出来**，而且界和预算要配套。

核心做法（PL-MBRO）：

1. **对每个不确定参数做 k-medians 聚类**，把历史日曲线分成若干个「概率层」（probability layers）——每个层代表一类典型形态。
2. **每个层里用三类代表来刻画偏差**：簇中心（中位数）当作「平衡代表」（balanced），簇内偏好的分位数当作「乐观代表」（optimistic），偏坏的分位数当作「悲观代表」（pessimistic）。这样偏差界不再是全样本统一分位数，而是**条件在具体概率层上的、参数专属的界**。
3. **预算从经验簇概率自动推导**：某个层在历史里出现的频率越高，就映射成越大的整数预算，覆盖整个 96 个 15 分钟时段。界和预算就这样「一个来源、自动配套」。
4. **鲁棒内层问题决定哪些时段最不利**：在给定预算下，内层 min-max 找出对调度最不利的偏差层组合。

对比基准（固定分位数 MBRO），在样本内/样本外测试里，PL-MBRO 在乐观、平衡、悲观三种策略下都拿到更好的实际经济收益，样本内最高提升 92.7%、样本外 57.3%（相对于基准实际利润的绝对值）。

## 3. 算法/模型框架说明

```
┌─────────────────────────────────────────────────┐
│  离线标定阶段（数据驱动）                        │
│  对每个不确定参数（电价/可再生/负荷）：           │
│   ① k-medians 聚类历史日曲线 → 概率层            │
│   ② 簇中位数 → 平衡代表                          │
│      簇内偏好/偏坏分位数 → 乐观/悲观代表          │
│   ③ 经验簇概率 → 整数全时段不确定性预算           │
│  ↓                                               │
│  输出：参数专属的偏差界 + 预算向量                │
└─────────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────────┐
│  在线竞价阶段                                    │
│  MBRO 竞价模型（无场景 MILP）：                  │
│   min  竞价成本                                  │
│   s.t. 多偏差层鲁棒约束                          │
│        预算约束（哪些时段允许到最坏层）           │
│        鲁棒内层：找对调度最不利的偏差层组合       │
│  ↓                                               │
│  日前 + 二次备用市场竞价决策                     │
└─────────────────────────────────────────────────┘
```

关键点：界与预算「同源自动生成」，且保持 MBRO 无场景 MILP 的可解性优势。

## 4. 关键创新点

1. **数据驱动的界-预算联合标定**：摆脱固定分位数 + 外部预算的拍脑袋式做法，界和预算从同一套聚类结构里自动、配套地生成。
2. **条件化的偏差界**：偏差界不再是全样本一刀切，而是条件在具体概率层上，更贴合真实分布形态。
3. **风险态度可调**：通过选择分位数水平（乐观/平衡/悲观）显式表达风险态度，且三种策略都能稳定优于基准。
4. **保持可解性**：在提升鲁棒性的同时，竞价问题仍是场景无关的 MILP，工程可落地。

## 5. 与已有方法的区别

| 维度 | 传统固定分位数 MBRO | 本文 PL-MBRO |
|------|--------------------|-------------|
| 偏差界 | 全样本统一分位数 | 条件于概率层、参数专属 |
| 预算 | 外部指定/灵敏度分析 | 经验簇概率自动推导 |
| 界-预算关系 | 脱节 | 同源自动配套 |
| 风险态度 | 单一 | 乐观/平衡/悲观显式可调 |
| 样本外表现 | 基准 | +57.3% |

## 6. 为什么值得关注

鲁棒优化在电力竞价里最大的工程痛点就是「不确定性集怎么设、预算怎么给」，这篇文章给出了一套**数据驱动、可解释、可调节**的标定方案，且不牺牲 MILP 的可解性。对我研究的启示：

- 「聚类概率层」的思路可以平移到分布鲁棒优化（DRO）的模糊集构建、鲁棒机组组合（RUC）的净负荷不确定性建模。
- 把「风险态度」显式参数化（乐观/平衡/悲观分位数），让决策者可以像调旋钮一样权衡保守度与收益，实用性强。
- VPP 聚合 + 日前/备用多市场联合竞价正是我关注的方向，PL-MBRO 可作为竞价层的鲁棒内核。

## 7. 待思考的问题

- k-medians 的簇数 k 如何选择？对结果敏感吗？论文似乎未系统讨论。
- 经验簇概率直接映射为整数预算，样本少时概率估计噪声大，是否会引入偏差？
- 只用了历史数据聚类，没有考虑分布偏移（气候变、市场规则变），鲁棒性标定会失效吗？
- 与 Wasserstein/矩模糊集等 DRO 方法相比，MBRO 的多界结构在保守度上孰优孰劣？缺乏直接对比。
- 能否把「风险态度分位数」也做成可学习参数，端到端地优化？
