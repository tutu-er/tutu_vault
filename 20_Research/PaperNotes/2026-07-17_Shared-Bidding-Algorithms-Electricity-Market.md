# Shared Bidding Algorithms and Competition: Evidence from Electricity Markets

## 1. 解决了什么问题

越来越多的电力市场参与者（尤其是电池储能）把竞价决策外包给第三方算法提供商。当多个竞争者的电池用同一家算法公司时，会不会**隐性合谋**？这比传统的"同一个人持有多个资产"更难监管——因为资产所有权是分散的，但算法逻辑是共享的。**本文用澳大利亚NEM的5分钟级实际报价数据，第一次证实了"共享算法提供商"会导致竞争对手之间内化彼此利润、损害消费者。**

## 2. 核心方法解读（师兄给你讲）

这篇是实证经济学的范式，但数据之精细令人咋舌：

**数据层面**：澳大利亚NEM的电池报价数据，5分钟一条，可以追溯到每家电池用的是哪家autobidder（自动竞价服务商）。这提供了一个天然实验室——同一个算法提供商手上的不同电池，到底报价有多"同步"？

**发现一：报价共移（co-movement）**。同一算法商的不同电池报价确实高度相关，而且——有意思的是——当监管披露改革让"稀缺状态"信息更容易被观察到之后，这种共移反而更强了。这暗示：是共同的信息导致同步，还是算法在故意协同？

**发现二：反事实反推**。为了区分"共享信息导致的自然同步"和"为了共同利润最大化而协调"，作者做了个很聪明的事：**估计每个电池的动态储能价值（dynamic value of stored energy），然后在假设"不以压低对手兄弟电池收入为前提"的条件下重新清仓（reclear the market）**。结果发现：真实报价中，电池频繁放弃了本该有利可图的机会——恰好是那些"如果出清就会压低同一个算法商其他电池收入"的时机。而且估算出来对兄弟电池利润的"内化权重"接近1（即把兄弟的利润当自己的利润一样重视）。

**发现三：门槛效应**。这种行为只在算法商的近边际电池容量份额超过约30%时才出现（对应装机份额约20%）。低于这个门槛，算法的市场力不足以影响价格。

**成本量化**：当前NEM电池舰队因这种行为，消费者每年多付约 550万美元。

## 3. 算法/模型框架说明

```
数据: 澳大利亚NEM 5min报价 + autobidder归属识别

Step 1: 报价共移分析
  - 计算同一算法商内电池报价的相关性
  - 对比披露改革前后共移程度变化

Step 2: 结构模型估计
  - 估计每电池的动态储能价值函数
  - V(SOC, price) = 即时套利收益 + 期望未来价值

Step 3: 反事实模拟
  - 假设电池只最大化自身利润（不含兄弟电池）
  - 用估计的价值函数重新生成最优报价
  - reclear the market → 对比真实出清结果

Step 4: 利润内化权重估计
  - 真实报价 = argmax { 自身利润 + θ × 兄弟电池利润 }
  - 估计 θ ≈ 1（利润内化接近完全）

Step 5: 门槛分析
  - 滚动窗口回归识别θ显著>0的市场份额门槛 → ~30%近边际份额
```

## 4. 关键创新点

1. **第一手实证证据**：首次用实际电力市场高频数据确认"算法共享导致的隐性合谋"
2. **信息 vs 合谋的分离**：用电池动态价值估计+反事实模拟巧妙分离了这两个混杂因素
3. **提出监管新维度**：传统监管看"资产所有权集中度"，但这篇说"算法提供商集中度"是一个被忽视的新维度
4. **门槛量化**：不是所有共享算法都会导致合谋——给出了可操作的"~30%近边际份额"安全线

## 5. 与已有方法的区别

- 与传统市场势力研究：关注的不再是谁持有资产，是谁的算法在替资产做决策
- 与算法合谋理论：提供了实证支撑（之前多为理论/实验室研究）
- 与电力市场监管：指出了一个盲区——即使资产所有者的HHI不高，算法层的集中也可能出问题

## 6. 为什么值得关注

- **方向高度相关**：如果你在做电力市场竞价、VPP聚合、储能套利策略，这篇直接告诉你：算法设计时要考虑"多用户共享"的博弈效应
- **政策启示**：AI在电力市场中的应用需要"算法层"的监管视角，而不仅仅是"资产层"
- **方法可复用**：动态储能价值估计+反事实模拟的方法论可以迁移到其他市场（如中国的现货市场试点）

## 7. 待思考的问题

1. 中国的电力现货市场正在建设中，当储能/虚拟电厂大量使用AI竞价算法时，会不会出现类似问题？监管框架需要提前设计
2. 如果算法商故意差异化服务（给不同客户不同参数），能否规避检测？这会导致"看似不同、实则协同"的局面
3. 文章中主要是电池储能，但VPP聚合了多种DER（光伏+储能+负荷）——共享算法在多资源类型聚合中的合谋效应可能更复杂
4. "算法提供商"这一层是否需要注册/监管？如何在不阻碍技术创新的前提下防止隐性合谋？
