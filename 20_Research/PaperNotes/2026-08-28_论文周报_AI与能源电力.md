# 论文周报：AI 与能源/电力系统（2026-08-28）

> 整理时间：2026-08-28 ｜ 来源：arXiv（cs.AI / cs.LG / eess.SY / math.OC 交叉）

---

## 一、大模型 / AI Agent

**1. PowerAtlas：电力—算力协同调度的 LLM-Agent 框架**（Kaiwen Jiang 等，北邮 + 国网辽宁 + 南洋理工）
- 链接：https://arxiv.org/abs/2607.26710
- 核心问题：AI 负载让数据中心变成大规模、易波动但可时空转移的电网负荷，通用 LLM 直接生成的调度常违反潮流约束、导致弃荷；需要一个既满足电网运行规则、又满足算力任务 SLA 的联合调度方案。
- 方法关键词：LLM-Agent、电力-算力协同调度（ECCS）、机组组合 + 任务放置联合建模、Feasibility-Aware GRPO（FA-GRPO）、确定性验证器、ECBench 基准
- 与我的关联：把"机组组合（UC）+ 算力调度"耦合成一个 LLM 决策闭环，是 AI×电力系统最直接的交叉范式，可借鉴其"物理可行性奖励对齐"思路到 VPP/市场决策。

**2. TwinGridShield：LLM 电网智能体动作的运行时授权层**（Md Fazley Rafy）
- 链接：https://arxiv.org/abs/2608.15391
- 核心问题：LLM 辅助能量管理能把自然语言转成结构化电网指令，但"语法合法"≠"物理可行"。本文在动作释放前，用确定性网络数字孪生逐条校验连通性、支路潮流、发电机与切负荷不变量。
- 方法关键词：运行时授权（runtime authorization）、确定性网络孪生、DC 潮流校验、哈希链日志、模型失配鲁棒性
- 与我的关联：LLM Agent 落进电网控制闭环的"安全闸门"，回答"AI 决策如何被物理验证"这一关键问题。

**3. 基于 LLM 的分层协调控制 + Continuation-Aware GRPO**（Changhong He 等，北航 + 百度）
- 链接：https://arxiv.org/abs/2608.15041
- 核心问题：多交互单元系统的协调，难点在系统耦合难建模、运行信息异构、底层动作须满足严格约束；用 LLM 做高层协调、任务专用控制器/优化器生成可执行动作。
- 方法关键词：LLM 分层协调控制、Continuation-Aware GRPO、异构上下文推理、VPP 能量管理、简化模型训练 + 真实仿真器评估
- 与我的关联：把"LLM + 强化学习 + 分层控制"结合并验证于 VPP，正是大模型、RL、VPP 三个方向的交汇点。

## 二、强化学习 / 优化

**4. 用强化学习削减 AI 数据中心能耗：LLM 训练的实测功率控制**（Eliseo Curcio）
- 链接：https://arxiv.org/abs/2608.11226
- 核心问题：RL 后训练主导语言模型开发，但数据中心用"工作负载无关"的静态功率帽 + 反应式降频，无差别拖慢硬件。本文用 PPO 元控制器实时调整生成参数，实测削减功率越限 89.8% 且吞吐提升 18.1%。
- 方法关键词：PPO 元控制器、功率遥测（半秒级）、GRPO 训练、执行器权威（actuator authority）分析
- 与我的关联：AI 本身成为可控柔性负荷，是"数据中心灵活性 + RL"的工程落地样本。

**5. UNION：面向拓扑变化实时运行的统一 AC-OPF 框架**（Kyungnam Park 等，西江大学 Hongseok Kim 团队）
- 链接：https://arxiv.org/abs/2608.25784
- 核心问题：学习型 AC-OPF 多为"单系统/单拓扑"训练，且难以保证每个运行约束都满足；本文一个模型跨 7 个系统联合训练，含 4492 节点韩国真实电网。
- 方法关键词：边感知 GNN（EA-GNN）、标量门控聚合（SGA）、稀疏可微隐式层（嵌入潮流方程）、原始-对偶训练、确定性可行修复层
- 与我的关联：OPF 深度学习代理的方向标杆，物理一致 + 拓扑泛化的思路可直接迁移。

**6. 多相配电网 AC-OPF 的可扩展自监督学习**（Hoang T. Nguyen 等，含 Priya L. Donti / Deepjyoti Deka，MIT + GE Vernova）
- 链接：https://arxiv.org/abs/2608.25095
- 核心问题：现有学习型 AC-OPF 多面向平衡输电网，难以扩展到多相、不平衡、可重构的配网馈线；本文提出 Penalty+SLFS 自监督框架，无需标注最优解，直接从目标与约束训练。
- 方法关键词：自监督学习、可微不动点潮流求解器、Sherman-Morrison-Woodbury 拓扑更新、配网重配置
- 与我的关联：配网级 DER 协调 + OPF 的可扩展路线，与 VPP/DER 聚合场景高度相关。

## 三、电力市场 / VPP / 逆优化

**7. 用数据驱动逆优化近似 VPP 的能量-调频可行域**（Ruike Lyu, Hongye Guo, Qixin Chen，清华）
- 链接：https://arxiv.org/abs/2608.25248
- 核心问题：系统运营商将允许 VPP 以整体提交可行域（FR）参与出清；现有解析法聚合 FR 泛化性差。本文用"虚拟电池"模型近似 VPP 聚合可行域，并用逆优化从多场景运行数据反推模型参数。
- 方法关键词：可行域聚合、虚拟电池模型、数据驱动逆优化、多场景运行数据
- 与我的关联：VPP/DER 聚合商参与市场出清的核心建模问题，逆优化思路可迁移到报价/竞价策略学习。

**8. 把快速响应能力纳入 VPP 辅助服务运行**（Qixing Liu, Ruike Lyu 等，清华 Hongye Guo 团队）
- 链接：https://arxiv.org/abs/2608.25247
- 核心问题：二次调频等辅助服务要求 VPP 具备足够响应能力来跟随快速变化的控制指令；忽视这一点会导致性能市场收入下降甚至被取消资格。本文在报价模型中引入机会约束，保证 VPP 快速响应能力以一定概率满足要求。
- 方法关键词：VPP 辅助服务、快速响应能力、机会约束（chance constraint）、基于性能的市场
- 与我的关联：VPP 辅助服务报价的随机优化建模，贴近"鲁棒/随机优化"方向。

## 二、推荐深入精读（3 篇）

1. **PowerAtlas（arXiv:2607.26710）**：LLM-Agent + UC + 算力调度的联合决策闭环，并配 ECBench 基准与真实部署，是"AI×电力系统"当前最完整、最对口的一条线，强烈建议精读。
2. **UNION AC-OPF（arXiv:2608.25784）**：跨系统、拓扑可变的统一 AC-OPF，物理一致（可微隐式层）+ 原始-对偶训练 + 修复层的组合干净有力，OPF 深度学习方向的方法论标杆。
3. **LLM 分层协调控制（arXiv:2608.15041）**：把 LLM、GRPO 强化学习、分层控制三者结合并在 VPP 能量管理上验证，是打通"大模型 + RL + VPP"三方向的理想切入点。
