# TSO-DSO Coordination for Flexibility Management Across Voltage Levels

- **论文标题**: TSO-DSO Coordination for Flexibility Management Across Voltage Levels
- **作者/机构**: Gustavo Valverde 等 (PSCC 2026 特邀综述)
- **链接**: https://arxiv.org/abs/2606.21998
- **关键词**: TSO-DSO Coordination, Flexibility Management, Distributed Energy Resources, Ancillary Services, Grid Codes

---

## 1. 解决了什么问题

随着分布式能源（DER）大量接入配电网，输电网（TSO）和配电网（DSO）之间的边界变得模糊。配电网中的灵活性资源（如分布式储能、EV、需求响应）可以为TSO提供辅助服务，但如何在不违背配电网物理约束和信息隐私的前提下实现跨电压等级的协调？这篇PSCC 2026特邀综述系统梳理了TSO-DSO协调的技术、市场和监管挑战。

## 2. 核心方法解读（像师兄讲给你听）

想象一个场景：TSO说"我需要100MW的向下调节能力"，配电网里有很多分散的小资源（屋顶光伏、家用电池、EV充电桩）可以提供。问题来了：
- DSO不知道哪些资源在什么约束下能提供多少灵活性
- TSO不知道配电网内部的拓扑和电压约束
- 如果TSO直接调用配网资源，可能造成配电网过载或电压越限

这篇综述不是提出一个新算法，而是把全世界各地不同电网"怎么解决这个问题"的实践和学术方案梳理了一遍。核心思路有三种：

**方案A - 分离式**: TSO和DSO各管各的，通过接口交换有限的聚合信息
**方案B - 协调式**: TSO和DSO共享一个协调平台，但不交换所有细节
**方案C - 集中式**: 一个统一调度平台管所有电压等级（理想但不现实）

## 3. 算法/模型框架

论文从三个维度梳理了协调方案：

```
            ┌──────────────────────────────────┐
            │      TSO-DSO 协调维度              │
            ├──────────┬──────────┬────────────┤
            │  技术维度  │  市场维度  │  监管维度   │
            ├──────────┼──────────┼────────────┤
            │ 灵活性聚合 │ 灵活性市场 │ 数据共享协议  │
            │ 潮流计算   │ 定价机制   │ 角色定义      │
            │ 电压控制   │ 结算规则   │ 责任划分      │
            │ 阻塞管理   │ 投标格式   │ 信息壁垒      │
            └──────────┴──────────┴────────────┘
```

- **灵活性聚合**: 如何将配网中大量DER的可调能力聚合成一个"虚拟柔性包"，同时保证聚合后的约束是tractable的
- **协调架构**: 从完全去中心化到完全集中化的频谱，以及中间的"共享TSO-DSO模型"方案
- **信息交换**: 在保护用户隐私和电网安全的约束下，什么信息需要跨界面传递

## 4. 关键创新点

1. **首次全面综述TSO-DSO协调的"技术-市场-监管"三角**: 不只是技术方案对比，还涵盖了欧洲、北美、亚洲不同市场设计下的实践
2. **识别出关键瓶颈**: 灵活性聚合的"可行性保真度"问题——聚合约束与真实物理约束之间的差距是当前最大技术挑战
3. **前瞻性方向**: 指出AI/ML（特别是GNN和RL）在DER聚合和灵活性估计中的潜力，以及数字孪生在协调中的角色

## 5. 与已有方法的区别

不同于单纯提出算法的论文，这篇综述的价值在于**分类框架**：
- 按信息交换粒度分为黑盒/灰盒/白盒协调
- 按市场参与模式分为独立市场、共享市场、无市场
- 按时间尺度分为长期规划、日前、实时协调

使得读者能快速定位自己的研究在整体版图中的位置。
