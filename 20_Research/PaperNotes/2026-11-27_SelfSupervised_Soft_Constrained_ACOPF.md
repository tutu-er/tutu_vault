## 1. 解决了什么问题

配电网里的 AC 最优潮流（AC-OPF）是非凸的，而且配网是**不平衡多相**系统，还要处理**软约束**（电压越限允许被罚，而不是硬切断），求解慢、难实时。已有「学习求解 OPF」的方法大多要先生成海量最优解当标签（监督学习），且多为单相/输电网、硬约束。本文要解决：**如何在无最优解标签的情况下，快速求解多相配电网的软约束 AC-OPF**。

## 2. 核心方法解读（师兄讲解版）

核心思想一句话：**不学「解」，直接最小化「目标函数本身」，让物理层保证可行性**。

具体流程：

1. **神经网络预测 DER 设定点**：输入是运行条件（负荷、发电）、开关拓扑、以及目标函数的权重（成本、弃光惩罚、越限惩罚的权重比例）。注意权重也作为输入——这意味着**同一个网络能处理不同偏好下的 OPF**，而不是为每种权重训练一个网络。

2. **物理投影层（DER projection）**：把网络吐出来的 DER 设定点，投影到设备的物理可行域上（比如逆变器容量圆/矩形约束、功率因数范围）。这保证「设备层」约束不被违反。

3. **可微 AC 潮流层（differentiable AC power flow）**：把投影后的设定点，喂进可微的交流潮流求解器，得到全网电压、潮流，从而**精确满足网络等式约束（功率平衡、基尔霍夫定律）**。

4. **软约束惩罚进目标**：越限（电压、支路潮流）不硬切，而是加进目标函数作为惩罚项。整个「预测 → 投影 → 潮流」的链条是**可微的**，所以可以直接对 OPF 目标函数做反向传播来训练网络——**完全不需要最优解标签**，这就是「自监督」。

一句话总结：网络学的是「给一个运行状态，怎么设 DER 才能让目标最小」，而可行性由「投影层 + 可微潮流层」结构性地兜住。

**效果**：在 123 / 240 / 906 节点不平衡多相系统上，目标值与 IPOPT（成熟非线性求解器）的差距仅 0.32% / 0.92% / 0.56%，而速度比 IPOPT 快 58～5272 倍。

## 3. 算法/模型框架说明

```
输入: 运行条件(负荷/发电) + 开关拓扑 + 目标权重(成本/弃光/越限惩罚)
              ↓
┌─────────────────────────────────────────────┐
│  神经网络: 预测 DER 设定点 (setpoints)        │
├─────────────────────────────────────────────┤
│  DER 投影层: 投影到设备物理可行域              │
│  (逆变器容量、功率因数、充放电范围)            │
├─────────────────────────────────────────────┤
│  可微 AC 潮流层: 精确满足网络等式约束          │
│  (功率平衡 + 基尔霍夫定律, 多相)              │
└─────────────────────────────────────────────┘
              ↓
  目标 = 运行成本 + 弃光惩罚 + 软约束越限惩罚
              ↓
  反向传播直接最小化目标(自监督, 无最优解标签)
```

- **模型**：NN（预测）→ 投影层（设备可行）→ 可微潮流层（网络等式），端到端可微
- **训练**：自监督，直接最小化 AC-OPF 目标，无需 IPOPT 生成标签
- **软约束**：越限进目标函数惩罚，而非硬约束
- **权重作为输入**：单网络覆盖多种偏好
- **验证**：123/240/906 节点，目标 gap 0.32~0.92%，加速 58~5272×（对比 IPOPT）

## 4. 关键创新点

1. **自监督、无标签**：彻底摆脱「用求解器生成训练标签」的昂贵流程
2. **投影层 + 可微潮流层**：把「可行性」从「学习目标」变成「网络结构」，结构性保证设备约束与网络等式
3. **软约束 AC-OPF**：贴合配电网真实运行（越限用惩罚而非硬切）
4. **目标权重作输入**：一个网络适配多种调度偏好，工程上更实用
5. **多相不平衡系统**：少见地处理了配网多相 + 开关拓扑变化

## 5. 与已有方法的区别

| 维度 | 传统学习 OPF | 本文 |
|------|-------------|------|
| 标签 | 需要大量最优解 | 自监督，无标签 |
| 可行性 | 靠损失项/惩罚「学」 | 投影层+可微潮流「结构性」保证 |
| 约束类型 | 多为硬约束 | 软约束（越限惩罚） |
| 系统 | 多为单相/输电网 | 多相配电网 + 拓扑 |
| 偏好 | 固定权重 | 权重作输入，可切换 |

## 6. 为什么值得关注

Priya Donti（Climate Change AI 创始人，可微优化/differentiable optimization 的代表人物）团队的工作，方法干净、代码开源，是「可微优化 + 自监督」在电力系统上的一个标杆。对我做「学习加速 OPF / 含 DER 的优化」很有用：它示范了「投影层 + 可微物理层 + 直接最小化目标」这套范式，这套范式可以迁移到很多带物理约束的调度问题（OPF、DER 聚合、VPP 可行域逼近）。

## 7. 待思考的问题

- 软约束的**惩罚权重怎么选**？权重敏感度高不高？会不会导致某些极端场景下越限被「过度牺牲」？
- 可微潮流层在多相、含变压器的复杂拓扑上的**数值稳定性**和收敛性如何保证？
- 目标 gap 虽然小，但**解的质量（是否接近全局最优）**在非凸 AC-OPF 上没有理论保证，只能数值上看 gap。
- 「权重作为输入」让网络能覆盖不同偏好，但偏好空间连续、无限，**泛化到训练时没见过的权重组合**效果如何？
- 能否把「自监督 + 投影层 + 可微潮流」的思路，迁移到我关心的 VPP 可行域 / DER 聚合问题上，作为快速近似的在线求解器？
