# Shift or curtail? How much data-center flexibility is worth depends on the host power grid

- **论文信息**: Saroj Khanal, Geon Roh, Boyu Yao, Abraham Silverman, Dennice Gayme, Charalambos Konstantinou, Jip Kim, Yury Dvorkin，arXiv:2608.19622，2026-08
- **链接**: https://arxiv.org/abs/2608.19622
- **领域**: 数据中心灵活性 / 电网容量扩展规划 / 电力市场 / 政策
- **备注**: 已投 Nature Energy

---

## 1. 解决了什么问题

AI 数据中心爆发式增长，若按"刚性负荷"接入电网，会导致电网过度建设、资本搁浅（stranded capital）。数据中心理论上可以"灵活"运行（时移负载、中断负载），从而推迟电网投资——但这种灵活性的**价值到底值多少钱**，取决于它接在什么样的电网上、用的是哪种灵活机制。本文就是想把这个"价值"算清楚。

## 2. 核心方法解读（师兄讲给你听）

师兄给你打个比方：同样是一台能随时"让路"的大功率负载，你把它接到 A 电网和 B 电网，它的价值可能天差地别。

- 如果电网是**市场化、以化石能源为主**（比如美国 PJM），那么瓶颈在"空间"——某些区域负载已经顶到上限了。这时数据中心的灵活性价值体现在**跨区域时移（spatial shifting）**：把算力负载从这个区挪到那个区，就不用再为紧张区域新建燃气/核电了。
- 如果电网是**碳配额约束、集中调度**（比如韩国），瓶颈在"时间"——中午光伏大发、晚上缺电。这时价值体现在**时间上时移（temporal shifting）**：把负载挪到中午吃光伏，就不用新建气电和储能了。

作者的做法很直接：把数据中心负载分成三类——**刚性（firm）、灵活（flexible）、可中断（interruptible）**，然后把它们塞进一个**容量扩展规划（capacity expansion）**模型里，在两种完全不同的电网（PJM vs 韩国）上各跑一遍，看灵活性机制到底省了多少钱、推迟了多少发电装机。

## 3. 算法/模型框架说明

```
数据中心负载分类：
  ┌──────────┬──────────────┬────────────────┐
  │ 刚性 firm │ 灵活 flexible │ 可中断 interruptible │
  └──────────┴──────────────┴────────────────┘
                    │ 嵌入
                    ▼
       容量扩展规划模型（capacity expansion）
                    │
   ┌────────────────┴────────────────┐
   ▼                                 ▼
市场型电网（PJM, 化石为主）      集中调度电网（韩国, 碳配额）
   → 价值是"空间"的               → 价值是"时间"的
   → 跨区时移负载                → 时移到中午光伏时段
   → 2028 省 6% 系统成本         → 2028 让 0.5 GW 光伏值得建
   → 2038 省 19%，少建 4.4/8.9 GW 气/核  → 2038 少建 1.2 GW 气 + 0.3 GW 储能
```

核心结论要点：

- **PJM**：灵活性价值是"空间的"，跨区时移在 2028/2038 分别降低系统成本 6% / 19%，避免 4.4 GW 和 8.9 GW 的气电+核电装机；
- **韩国**：价值是"时间的"，把负载挪进中午光伏时段，2028 年让 0.5 GW 额外光伏变得经济，2038 年少建 1.2 GW 气电 + 0.3 GW 储能；
- **真实事件形状约束（event-shape limits）**会削弱"可中断（curtailment）"的价值——即"一刀切断电"远不如"精细时移"值钱。

## 4. 关键创新点

1. **显式区分三类负载灵活性**（firm / flexible / interruptible），而非笼统地"数据中心=可调负载"
2. **在两种制度迥异的真实电网（PJM vs 韩国）上对照**，揭示"灵活性价值取决于宿主电网"这一核心论点
3. **把数据中心灵活性纳入容量扩展规划**，直接量化其"推迟投资 / 少建装机"的资本价值
4. **区分空间时移 vs 时间时移**两种价值来源，给出可操作的政策启示

## 5. 与已有方法的区别

| 方法 | 关键区别 |
|------|----------|
| 单数据中心 PUE/节能研究 | 只看单站点能耗，不看对电网的宏观投资影响 |
| 数据中心与电网"联合调度"研究 | 多为短期运行层面，本文站在长期规划（capacity expansion）层面 |
| 笼统"可调负载"建模 | 本文细分 firm/flexible/interruptible，并量化 curtailment 的价值折损 |
| 单一市场研究 | 本文做 PJM vs 韩国双电网对照，结论更具一般性 |

## 6. 为什么值得关注

- **方向高度相关**：AI 数据中心 + 电力系统是当前最热交叉点之一，且直接挂钩"灵活负荷 / 需求侧资源 / 容量规划"这条线
- **顶刊信号**：投 Nature Energy，作者团队（Yury Dvorkin、Dennice Gayme 等）是电力+数据中心的头部团队
- **结论有政策价值**：说明"灵活性采购"应该因地制宜，不能一刀切，对 VPP/DER 聚合与灵活负荷市场设计有直接启发

## 7. 待思考的问题

1. 灵活性被简化成"时移/中断"，没有建模数据中心内部的算力调度（如推理任务、训练任务的不同灵活性），能否细化？
2. 两种电网对照很漂亮，但结论能否推广到"含高比例风光 + 市场化"的中国省级电网场景？
3. curtailment 价值被"事件形状约束"削弱，这个约束在现实中到底怎么定？谁来补偿数据中心被中断的损失？
4. 能否把本文的"灵活性价值"框架与 VPP/DER 聚合商的多市场收益建模打通，形成统一的价值量化？
