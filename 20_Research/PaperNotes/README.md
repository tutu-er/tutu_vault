# 📚 单篇论文深度笔记

本目录存储对高价值论文的**方法论解读**，由八千代每周整理时自动生成。

## 目录结构

```
PaperNotes/
├── README.md              # 本文件（索引）
├── _templates/
│   └── methodology-note.md # 方法论文解读模板
├── 2026-03-09_...md        # 按日期+标题命名的笔记
└── ...
```

## 笔记格式

每篇笔记包含：
1. 论文解决了什么问题
2. 核心方法解读（通俗易懂）
3. 算法/模型框架
4. 关键创新点
5. 与已有方法的区别
6. 值得关注的理由
7. 待思考的问题
