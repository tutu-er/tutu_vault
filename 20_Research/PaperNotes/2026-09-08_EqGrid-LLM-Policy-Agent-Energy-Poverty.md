# EqGrid：面向能源贫困公平的接地、省算力 LLM 策略智能体

- **论文**: Grounded, Compute-Efficient LLM Policy Agents for Energy-Poverty Equity in Physically-Constrained Peer-to-Peer Energy Markets
- **作者**: Kunal Jadhav 等
- **来源**: arXiv:2609.01918（cs.CL），EMNLP 2026 NLP4PI Workshop
- **链接**: https://arxiv.org/abs/2609.01918
- **领域**: LLM 策略智能体 · 多智能体 RL · P2P 电力市场 · 公平 · 省算力

---

## 1. 解决了什么问题

能源贫困（energy poverty）几乎没被 NLP-for-social-good 关注过，现有工作要么是静态检索/问答，要么依赖高碳排的云端大模型——这在人道主义场景里形成一种"计算讽刺"。本文要回答：能否用**低频率、开源、省算力**的 LLM 策略智能体，在**物理约束的 P2P 能源市场**里做定价/补贴/碳边界决策，既改善公平又不违反电网约束、不抬高总成本？

## 2. 核心方法解读（师兄讲给你听）

作者搭了一个**闭环仿真**：一个低频的 LLM 策略智能体负责"定政策"（电价、碳边界、定向补贴），一群高频的多智能体 RL 交易者负责"执行交易"（连续双向拍卖），物理层用 IEEE-33 母线配电网 + 动态运行包络（DOE）保证交易不越界。

三条主线：

1. **接地（grounded）**：用地区匹配的社会人口统计造出"真实可信的家庭画像"，并用真实智能电表数据校验负荷曲线的形状与量级——不是拍脑袋的角色设定。
2. **公平指标**：形式化定义能源负担（Energy Burden）、能源负担基尼系数、低收入高成本（LIHC）等指标，量化干预效果。
3. **省算力前沿**：把 235B 的教师模型压缩到亚 1B 可在笔记本跑的模型，测公平性能在压缩后还剩多少，并按"每次决策的能耗/碳排"算性价比。

**关键安全设计——解耦安全（decoupled safety）**：LLM 只负责设边界（价格/碳/补贴上下限），一个"校验-投影电网 gate"负责落地执行。结果：电网约束违规 0 次（直接让 LLM 控制时是 55 次）。

**效果**：LLM 政策把能源负担基尼系数从 0.351 降到 0.305，平均负担降 28%，还省钱（优于调好的规则基线）；3B 激活模型保留 95% 收益、推理能耗约为教师模型 1/9；0.8B 端侧模型保留 92%、能耗约 1/24。

## 3. 算法/模型框架说明

```
LLM 策略智能体（低频）──设电价/碳边界/补贴──┐
                                          ▼
         校验-投影电网 gate（安全执行层）
                                          │
                 ┌────────────────────────┤
                 ▼                        ▼
        多智能体 RL 交易者（高频）  IEEE-33 配电网 + DOE
        （连续双向拍卖）            （物理约束，防越界）
                 │
                 ▼
         公平指标：能源负担 / 基尼 / LIHC
                 │
                 ▼
         省算力前沿：235B → 3B → 0.8B 的公平-能耗权衡
```

## 4. 关键创新点

1. **解耦安全设计**：LLM 设边界、电网 gate 兜底执行，把"LLM 直接控网"的安全风险从根源上隔离；
2. **接地画像 + 真实数据校验**：让社会仿真不再悬浮；
3. **形式化公平指标**：首次把能源贫困公平做成可测量的优化目标；
4. **省算力前沿**：系统回答"把 LLM 压缩后公平性能还剩多少、能耗省多少"。

## 5. 与已有方法的区别

| 方法 | 关键区别 |
|------|----------|
| 静态检索/问答式 LLM | 不参与决策闭环，无实际市场影响 |
| 云端大模型决策 | 碳排高，与"帮穷人"目标自相矛盾 |
| 直接让 LLM 控制电网 | 约束违规多（本文测得 55 次） |
| **EqGrid** | **解耦安全 + 接地画像 + 公平指标 + 省算力蒸馏** |

## 6. 为什么值得关注

- **解耦安全范式可复用**："LLM 只设高层边界、优化器/求解器做硬约束执行"，与我方 VPP/市场 Agent 的安全设计思路高度契合；
- **省算力蒸馏结论实用**：亚 1B 端侧模型保留 92% 收益、能耗 1/24，为 VPP 边缘部署 LLM 提供了量化依据；
- **跨学科视角**（NLP × 电力 × 公平）带来新鲜的度量与评估框架。

## 7. 待思考的问题

1. 解耦安全里"LLM 设边界"的边界本身如何保证合理？若 LLM 设的边界导致市场无可行解怎么办？
2. 多智能体 RL 交易者的策略在 DOE 约束下如何保证收敛、稳定？是否会出现共谋/价格操纵？
3. 235B 教师模型蒸馏到 0.8B 的过程是否引入了偏差？在不同地区画像上公平结论是否稳健？
4. 这套"政策 LLM + 执行 gate"能否迁移到 VPP 聚合商做日前定价/备用报价的场景？
