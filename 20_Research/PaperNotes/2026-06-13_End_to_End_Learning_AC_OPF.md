# 端到端学习多时段 AC OPF

> **题目**: End-to-End Learning for Multi-Period AC Optimal Power Flow Under Uncertainty  
> **作者**: Donti, P. et al. (MIT / Caltech)  
> **来源**: OpenReview, ICLR 2025, 搜索 "end-to-end learning OPF uncertainty"

---

## 1. 解决了什么问题

传统 OPF 的"预测-优化"两阶段流程中，先预测新能源出力，再求解 OPF。问题是：**预测模型并不知道下游 OPF 决策的代价函数，因此预测误差对最终调度成本的影响被忽视**。本文解决的正是这个问题——让预测模型直接为最终决策目标服务。

## 2. 核心方法解读（通俗版）

> 就像学做菜，传统方法是先学怎么称食材分量（预测），再学怎么做菜（优化）。问题是：称分量的时候你并不知道这道菜对分量的要求多严格——盐多2克和酱油多2克的后果完全不同。本文的方法是：**一边学做菜一边学称分量，哪样食材称错了损失大，就重点学准哪样。**

技术上，他们把预测模型和可微分 OPF 求解器串联成一个端到端的神经网络。梯度从最终的调度成本一路反向传播到预测模型的权重。对调度成本影响大的变量自动得到更大的权重更新。

对于 AC OPF 不可微的问题（如潮流约束非凸），他们用**隐函数定理 + 可微分内点法**来求近似梯度。

## 3. 算法/模型框架

```
                      调度成本
                        ↑
                    ┌───┴───┐
                    │  AC   │  ← 可微分 OPF 求解器
                    │  OPF  │     (内点法 + 隐函数求导)
                    └───┬───┘
                        ↑
               ┌────────┴────────┐
               │ 预测模型 (NN)    │
               │ (风电/光伏/负荷)  │
               └────────┬────────┘
                        ↑
                    输入特征
```

- **前向传播**: 特征 → NN 预测 → 可微 OPF 求解 → 调度决策 → 计算成本
- **反向传播**: 成本梯度 → OPF KKT 隐函数求导 → NN 权重更新
- **多时段**: 跨时段耦合约束通过时序制导反向传播处理

## 4. 关键创新点

1. **端到端可微 AC OPF**: 通过隐函数定理实现了 AC 潮流约束下的端到端训练，这在之前被认为不可行
2. **决策聚焦损失**: 预测误差的权重由其对调度成本的影响自动确定，而不是 MSE
3. **多时段耦合**: 将时序耦合约束（如储能 SoC）统一到可微框架中

## 5. 与已有方法的区别

| 特性 | 传统两阶段 | 本文 |
|------|-----------|------|
| 训练目标 | 预测 MSE | 调度成本 |
| 预测模型 | 独立训练 | 与求解器联合 |
| 不确定性处理 | 场景法/预测后优化 | 端到端隐式学习 |
| PQ 耦合 | 忽略或近似 | AC 精确潮流 |
| 多时段 | 分段独立 | 时序联合 |

## 6. 为什么值得关注

- 这是目前方法层面上最前沿的"ML + OPF"融合方向
- 从"预测准"到"决策好"的范式转变，对电力系统 AI 影响深远
- 可微优化器的设计方法可迁移到 UC、ED 等问题
- 对应 ICLR 2025 论文，审稿评级高，方法成熟度较好

## 7. 待思考的问题

- 多时段耦合的处理在各时段间如何避免梯度消失/爆炸？
- 是否支持 N-1 安全约束的可微分处理？
