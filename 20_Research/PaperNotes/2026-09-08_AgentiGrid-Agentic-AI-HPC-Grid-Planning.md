# AgentiGrid：Agentic AI × 高性能计算做电网规划潮流分析

- **论文**: Integrating Agentic Artificial Intelligence with High-Performance Computing for Grid Planning
- **作者**: Slaven Peles 等（美国橡树岭国家实验室 ORNL / ExaGO 团队）
- **来源**: arXiv:2609.04544（eess.SY），EnergyCon 2026
- **链接**: https://arxiv.org/abs/2609.04544
- **领域**: LLM Agent · AC-OPF · 高性能计算 · 电网规划

---

## 1. 解决了什么问题

多场景潮流/OPF 研究是个"改参数 → 跑 HPC 求解器 → 看结果 → 再改"的反复闭环，人工驱动慢、依赖工程师经验。本文要让 LLM Agent 自主完成这个闭环，加速并简化大规模电网规划中的多场景潮流分析。

## 2. 核心方法解读（师兄讲给你听）

思路是给 LLM 配一个"会算数的机器人副手"，形成闭环：**LLM 负责决策，HPC 负责算**。

- Agent 观察当前结果 → 提出参数修改（如调整发电/负荷/拓扑）→ 调 ExaGO 求解器跑潮流/OPF（ExaGO 是 ORNL 的 HPC 潮流分析工具箱，支持确定性、随机、安全约束 OPF）→ 解读结果 → 决定下一步。
- 这个"观察-行动-解读-再行动"的循环就是典型的 ReAct 范式，只是把工具换成了 HPC 求解器。
- 三个关键设计：①**交互式中途 steering**（人可在搜索中途插手引导）；②**目标类型感知的后分析**（针对不同目标做不同解读）；③**并发变体探索**（并行探索多个潮流优化变体）。
- 前端用 Streamlit 做图形化启动器，实时可视化迭代进度、生成自然语言报告。

**结果**：能在 20 次迭代内自主收敛传输级约束的交流最优潮流（AC-OPF），近乎完美可靠。

## 3. 算法/模型框架说明

```
初始场景/参数
      │
      ▼
LLM Agent（决策层：提参数修改）
      │ 调用
      ▼
ExaGO HPC 求解器（执行层：确定性/随机/安全约束 OPF）
      │ 返回结果
      ▼
LLM 解读结果 → 判断是否收敛
      │ 未收敛 → 回到决策层
      ▼
  收敛 → 后分析 + 生成自然语言报告
      （全程支持人工中途 steering + 并发变体探索）
```

- 后端支持多 LLM：OpenAI / Anthropic / Ollama / Ollama Cloud
- 用 context-specific + task-specific 提示词增强

## 4. 关键创新点

1. **LLM + HPC 求解器闭环**：LLM 决策、求解器兜底算，二者能力互补——LLM 不懂高维数值、求解器不懂工程判断；
2. **求解器作为"硬约束执行器"**：所有物理/运行约束由 ExaGO 保证，LLM 不会输出不可行的方案；
3. **人机协同 steering**：不搞全自动黑盒，允许中途人工介入，更贴近工程落地；
4. **多场景并发探索**：加速规划研究。

## 5. 与已有方法的区别

| 方法 | 关键区别 |
|------|----------|
| 直接让 LLM 算潮流/OPF | LLM 数值能力差、易出错、无可行性保证 |
| 纯 HPC 求解器 | 快但每次要人工改参数、人工解读，无自主闭环 |
| 一般 LLM Agent + 工具调用 | 工具是"软"的（检索/计算器），无物理约束兜底 |
| **AgentiGrid** | **HPC 求解器做硬约束执行器 + LLM 做决策闭环 + 人工 steering** |

## 6. 为什么值得关注

- **Agentic AI 落地电网运行的完整范式**：把"LLM 提方案、求解器兜底"的分层结构讲清楚了，这是当前最可复用的 Agent + OPF 设计；
- **与我的方向高度相关**：同样的分层思路可迁移到 VPP 调度、市场出清——让 LLM 做高层决策、优化求解器做硬约束执行；
- 明确给出量化结果（20 次迭代内收敛 AC-OPF），可信度较高。

## 7. 待思考的问题

1. LLM 的"参数修改"动作空间如何设计？有没有可能给出导致求解器发散/无解的组合？
2. 20 次迭代收敛的规模多大？扩展到数千节点、含 N-1 时迭代次数与 token 成本是否可控？
3. "人工 steering"在多大程度上依赖专家？没有专家在场时自主性能否保持？
4. 能否把 Agent 学到的"改参经验"沉淀下来（如微调/记忆），减少重复推理成本？
