# Hyena Hierarchy: Towards Larger Convolutional Language Models

> **作者**: Michael Poli et al.  
> **会议**: ICML 2023  
> **关键词**: long convolution, subquadratic sequence modeling, gating, language model  
> **原文**: https://arxiv.org/abs/2302.10866

## 1. 解决了什么问题

Transformer 的 self-attention 在长序列上代价高。很多高效序列模型虽然复杂度更低，但在语言建模质量上难以真正替代 attention。

Hyena 要解决的是：能否设计一种不依赖 dense attention 的序列算子，在长上下文任务中具备更低复杂度，同时保持接近 Transformer 的语言建模能力？

## 2. 核心方法

Hyena 用“隐式长卷积 + 数据控制门控”替代注意力。它不是使用固定短卷积核，而是用参数化函数生成长卷积滤波器，从而覆盖很长的上下文。

一个简化理解是：

```text
输入序列 -> 多个投影分支
         -> 长卷积聚合远距离信息
         -> 门控根据当前 token 调节信息流
         -> 堆叠成 Hyena hierarchy
```

门控负责提供输入依赖性，长卷积负责高效传播长程信息。

## 3. 原理解释

Attention 的强大之处在于每个 token 可以动态选择关注其他 token。纯卷积的弱点是权重相对固定，输入适应性不足。Hyena 的设计是在二者之间折中：

- 长卷积提供全局感受野；
- 隐式滤波器减少显式存储长 kernel 的成本；
- 乘性门控让信息流依赖输入内容。

因此 Hyena 不是传统 CNN 复古，而是把卷积、门控和长序列隐式参数化组合起来。

## 4. 与 Transformer 的区别

| 维度 | Transformer Attention | Hyena |
|---|---|---|
| 信息混合 | token-token 动态权重 | 长卷积 + 门控 |
| 长度复杂度 | 二次 | 亚二次 / 更接近线性 |
| 长上下文效率 | 受 attention matrix 限制 | 更适合长序列 |
| 表达方式 | 显式 pairwise interaction | 隐式滤波与调制 |

## 5. 实验与结果

论文在语言建模、长程记忆和合成推理任务上展示 Hyena 能匹配或接近 attention 模型，并在长序列下获得明显速度优势。特别是在很长上下文时，Hyena 的效率优势会放大。

它的重要性不在于宣布 Transformer 结束，而在于证明 attention 不是唯一可扩展路线。

## 6. 为什么值得读

Hyena 是 Transformer 替代架构研究中的代表论文。它预示了后续 SSM、Mamba、Mamba-2 等路线的兴起：研究者重新认真看待卷积、递归、状态空间这些“旧工具”，并用现代硬件和大规模训练重新包装。

对长上下文 LLM 来说，Hyena 提醒我们：真正的瓶颈可能需要架构层面而不只是 kernel 层面的改变。

## 7. 局限与思考

- 在通用大规模 LLM 上全面替代 Transformer 仍需更多证据。
- 门控长卷积对复杂组合推理的表达能力边界不如 attention 直观。
- 实现和训练配方会显著影响实际收益。
- 后续 Mamba/SSM 路线与 Hyena 在思想上相近但机制不同，值得对比阅读。
