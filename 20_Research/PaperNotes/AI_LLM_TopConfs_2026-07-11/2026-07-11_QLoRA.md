# QLoRA: Efficient Finetuning of Quantized LLMs

> **作者**: Tim Dettmers et al.  
> **会议**: NeurIPS 2023  
> **关键词**: quantization, LoRA, NF4, paged optimizer, efficient fine-tuning  
> **原文**: https://arxiv.org/abs/2305.14314

## 1. 解决了什么问题

LoRA 已经降低了大模型微调的训练参数量，但基础模型本身仍要以较高精度加载到显存。对于 33B、65B 级别模型，单卡微调仍然困难。

QLoRA 要解决的是：能否把预训练模型压到 4bit 存储，同时仍然通过 LoRA 反向传播进行高质量微调，使普通研究者能用单张高显存 GPU 微调超大模型？

## 2. 核心方法

QLoRA 的基本结构是：

```text
冻结的 4bit 量化基础模型 + 可训练 LoRA 适配器
```

前向传播时用量化权重计算；反向传播时梯度穿过冻结的量化模型，更新 LoRA 参数。基础权重不更新，因此量化误差不会在主权重中累积。

论文提出三个关键组件：

1. **NF4**: 针对近似正态分布权重设计的 4bit 数据类型。
2. **Double Quantization**: 对量化常数再量化，进一步节省显存。
3. **Paged Optimizers**: 利用统一内存管理优化器状态，缓解长序列训练时的显存峰值。

## 3. 原理解释

普通量化可能损害训练，因为低精度权重更新会积累误差。QLoRA 避开了这个问题：量化后的基础模型只作为固定特征变换器，真正学习的参数是高效的 LoRA 分支。

可以理解为：

```text
h = Quantized(W) x + B A x
```

`Quantized(W)` 提供原模型能力，`BA` 负责下游适配。由于 `W` 不更新，训练稳定性主要由 LoRA 参数决定。

## 4. 与 LoRA 的区别

| 维度 | LoRA | QLoRA |
|---|---|---|
| 基础模型精度 | 通常 16bit / bf16 | 4bit |
| 训练参数 | LoRA 参数 | LoRA 参数 |
| 显存瓶颈 | 基础模型加载 | 显著降低 |
| 主要创新 | 低秩适配 | 量化基础模型 + 低秩适配 |

QLoRA 不是替代 LoRA，而是把 LoRA 和低比特量化组合成可用的大模型微调方案。

## 5. 实验与结果

论文展示了 65B 参数模型可以在单张 48GB GPU 上微调，并提出 Guanaco 系列模型。结果显示，QLoRA 在保持接近 16bit 微调效果的同时大幅降低显存消耗。

论文还系统分析了指令数据集、模型规模、评测方式和 GPT-4 作为评价器的可靠性问题，因此不仅是训练技巧论文，也是一篇开源 LLM 微调实践报告。

## 6. 为什么值得读

QLoRA 极大降低了大模型研究门槛。许多开源模型的领域适配、聊天微调、偏好微调都建立在 QLoRA 这类技术上。它的影响不只在算法，还在生态：让“下载基础模型，在本地微调一个可用助手”成为现实。

## 7. 局限与思考

- 4bit 量化对某些模型、任务和长上下文场景仍可能有精度损失。
- 评测中大量依赖自动评价，可能放大评价器偏好。
- QLoRA 适合适配，不等于能廉价完成高质量预训练。
- 显存降低后，数据质量、训练配方和评测可信度成为更主要瓶颈。
