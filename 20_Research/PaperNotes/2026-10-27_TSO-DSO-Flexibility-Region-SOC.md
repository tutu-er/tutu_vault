# Explicit Convex Inner Approximation of TSO-DSO Flexibility Regions via Exact Second-Order Cone Relaxation in Radial Networks

- **arXiv:** [2610.27897](https://arxiv.org/abs/2610.27897)
- **作者:** Wenyu Liu, Mario Paolone（EPFL, Distributed Electrical Systems Laboratory）
- **来源:** arXiv (eess.SY)
- **整理日期:** 2026-10-27

---

## 1. 解决了什么问题

TSO 和 DSO 协同需要把配电网的"灵活性"以可计算的形式交给 TSO。但用非线性 OPF 算出来的灵活性区域（Flexibility Region, FR）**没有可行性保证**（边界上的点可能实际不可达），而传统的凸松弛又可能"不精确"（松弛解与真实解对不上）。这篇论文要在辐射状配电网里，构造**保证 AC 可行、又是凸、还紧致**的灵活性区域显式内近似。

## 2. 核心方法解读（师兄视角）

先建立两个关键概念：

- **灵活性区域（FR）**：DSO 能向 TSO 提供的、在根节点上"有功-无功功率"的可达范围。理想情况下它是一个区域，TSO 在这个区域里随便选点，DSO 都能调度内部资源实现。
- **凸松弛的"精确性"（exactness）**：把非凸的 AC-OPF 松弛成凸问题后，如果松弛解恰好落在原非凸可行域内（即松弛不"放水"），就称这个松弛是精确的。精确的松弛才能保证松弛出来的边界是真实可达的。

这篇论文的思路是：

1. 用**增广松弛 OPF（AR-OPF）** 作为基础松弛。AR-OPF 是在经典二阶锥（SOC）松弛上加了额外的"增广"约束，让它比普通 SOC 松弛更紧。
2. 推导出**更不保守的 AR-OPF 精确性充分条件**，并推广到更一般的优化目标（不只是网损最小）。这是理论贡献的核心——给出"在什么条件下松弛一定精确"。
3. 建立**内部可行性分析**：证明在满足上述充分条件时，沿着"边界描出来的区域"的**内部所有点**都是 AC 可行的。也就是说，不光是边界点，整块区域都能真正实现。
4. 基于这些理论，设计两个**自适应算法**，把 FR 的显式内近似（一个凸集，比如多面体或 SOC 表示）构造出来。

最终在多个基准配网上验证：松弛残差始终很小、灵活性区域保留率高，说明这套方法给出的 FR 是"操作上可信"的——TSO 拿到这个凸区域去协同调度，不会出现"DSO 承诺了却实现不了"的尴尬。

## 3. 算法/模型框架

```
┌──────────────────────────────────────────────┐
│  辐射状配电网 AC-OPF (非凸)                  │

└──────────────────┬───────────────────────────┘
                   │
┌──────────────────▼───────────────────────────┐
│  推导 AR-OPF 精确性的充分条件（更不保守）    │

└──────────────────┬───────────────────────────┘
                   │
┌──────────────────▼───────────────────────────┐
│  自适应算法 ① ②：                           │

                   │
                   ▼

```

## 4. 关键创新点

1. **可行性保证**：相比"非线性 OPF 估计 FR 无保证"和"普通凸松弛可能不精确"，本文给出的 FR 内近似是**严格 AC 可行**的。
2. **更不保守的精确性充分条件**：把 AR-OPF 精确性条件放松，覆盖更多实际场景（含广义目标）。
3. **内部可行性分析**：证明了"边界内整块区域可行"，这是把"边界可行"推广到"区域可行"的关键一步，很多论文没做这一步。
4. **显式凸表示**：最终输出的是显式的凸内近似（不是黑箱），TSO 可以直接塞进自己的凸优化/市场出清模型。

## 5. 与已有方法的区别

| 方法 | 凸/可计算 | 可行性保证 | 紧致性 |
|------|----------|-----------|--------|
| 非线性 OPF 直接估计 FR | 非凸 | 无保证 | 紧 |
| 经典 SOC 松弛 FR | 凸 | 可能不精确 | 偏松 |
| 多面体近似（如 Ziegler 型） | 凸 | 有（内近似） | 偏保守 |
| **本文 AR-OPF 精确内近似** | 凸 | 严格保证 | 较紧（保留率高） |

## 6. 为什么值得关注

这直接命中我们做 **VPP/DER 聚合**的痛点：把一堆分布式资源的聚合灵活性，用一个"可信、凸、可提交"的区域表示出来，交给上层调度/市场。我们之前讨论的"聚合可行域（aggregated feasible region）"本质上就是同一个问题。这篇的"精确性条件 + 内部可行性 + 显式凸内近似"三步走，是把这个方向从"启发式"推向"有理论保证"的漂亮范本，很值得借鉴到我们的 DER 聚合模型里。

## 7. 待思考的问题

- 辐射状网络假设能否放松？带环网 / 弱环的配电网，SOC 松弛精确性条件还成立吗？
- "增广"约束具体加了什么？增加的复杂度 vs 带来的紧致性提升，性价比如何？
- 把 FR 显式凸内近似交给 TSO 后，TSO 的协同优化会怎么利用它？边界点的价格信号如何反哺 DSO？
- 如果 DER 出力带不确定性（光伏/负荷波动），确定性 FR 的可行性保证还能守住吗？是否需要往"鲁棒 FR"延伸？
- 我们的 VPP 聚合里，能否用同样的"精确松弛 + 显式内近似"思路，把储能、可调负荷的联合可行域做成凸的？
