# Adaptive Robust Optimisation for Frequency-Constrained Market Clearing Problem

- **arXiv**: [2611.31572](https://arxiv.org/abs/2611.31572)
- **作者/机构**: Özlem Mahmutoğulları, Hakan Ergun（KU Leuven, 比利时, 电气工程）
- **日期**: 2026-11-23
- **标签**: #自适应鲁棒优化 #市场出清 #机组组合 #频率安全 #惯量 #HVDC #ColumnAndConstraintGeneration

---

## 1. 解决了什么问题

高比例新能源 + 直流（HVDC）联网背景下，日前市场出清必须同时考虑两件事：一是新能源/负荷/HVDC 换流站**同时发生的不确定性**；二是**频率安全**（系统要有足够惯量和快速频率响应能力，否则扰动下会失稳）。现有出清模型要么忽略频率约束，要么用确定性/简单场景法处理不确定性。本文把两者结合起来，做**频率约束下的自适应鲁棒日前出清**。

## 2. 核心方法解读（师兄讲解版）

先把问题拆成两阶段（自适应鲁棒的经典范式）：

- **第一阶段（here-and-now）**：系统运营商决定机组组合、能量出清、备用采购——这些是「不确定性实现之前」就要拍板的。
- **第二阶段（wait-and-see）**：给定不确定性的**最坏实现**（新能源骤降 + 负荷骤升 + 换流站跳闸同时发生），系统重新平衡（再调度、切负荷）。

目标是最小化「第一阶段成本 + 最坏情形下的第二阶段成本」，也就是一个 **min-max-min** 结构：`min(第一阶段) max(最坏不确定性) min(第二阶段平衡成本)`。

**频率安全怎么加进去？** 作者显式加了两个约束：**惯量约束**（同步区内可用转动惯量要够，防止频率下降太快 RoCoF 超标）和**快速频率响应（FFR）约束**（能快速顶上的功率要够，防止频率跌到最低点 Nadir 以下）。并且允许 **HVDC 在可用裕度内提供紧急功率支援**（emergency power support）——这在高比例直流联网的欧洲/北海场景很关键。

**怎么解这个 min-max-min？** 用**列与约束生成（Column-and-Constraint Generation, C&CG）**算法：外层迭代地「加约束、加场景」，把最坏情形识别出来，逐步逼近鲁棒最优解。

**算例**：8 国北海测试系统，3 个同步区、16 个陆上竞价区、5 个海上风电场枢纽，通过网状 HVDC 相连。作者还比较了两种市场设计——**Home Market（HM，按所属国分区）**和 **Offshore Bidding Zone（OBZ，海上独立竞价区）**——在不确定性下的表现。

**结论亮点**：确定性解在最坏情形下非常脆弱；而 OBZ 因为把海上竞价区边界做出来，让线路阻塞在日前就「看得见」，从而能针对性地采购备用——日前成本略高，但实时切负荷大幅下降，**总成本反而更低**。而 HM 因为分不清「海上换流站跳闸」和正常运行，无法在日前对冲这种风险。

## 3. 算法/模型框架说明

```
目标: min_x  c(x)  +  max_ξ  min_y  q(y, ξ)     (min-max-min)

第一阶段 x: 机组组合(UC) + 能量出清 + 备用采购
              │
              ▼
第二阶段 ξ: 最坏不确定性(新能源↓ + 负荷↑ + HVDC换流站跳闸)
              │
              ▼
第二阶段 y: 最坏情形下再平衡(再调度 / 切负荷)

硬约束:
  • 惯量约束: Σ H_i·P_i ≥ H_req   (防 RoCoF 超标)
  • FFR 约束: Σ FFR_i ≥ ΔP_max     (防 Nadir 过低)
  • HVDC 紧急功率支援(在可用 headroom 内)

求解: Column-and-Constraint Generation (C&CG)
      → 外层主问题(加约束) / 内层子问题(识别最坏场景)
      → 迭代收敛到鲁棒最优
```

- **建模**：两阶段自适应鲁棒优化（ARO），min-max-min
- **频率约束**：惯量 + 快速频率响应（FFR），同步区层面
- **HVDC**：可提供紧急功率支援
- **算法**：C&CG 列与约束生成
- **算例**：8 国北海系统，比较 HM vs OBZ 两种市场设计

## 4. 关键创新点

1. **频率安全 × 鲁棒优化**：把惯量/FFR 约束显式纳入自适应鲁棒出清，填补了「鲁棒出清不关心频率」的空白
2. **HVDC 紧急支援建模**：允许直流在裕度内提供紧急功率，符合欧洲北海真实运行
3. **市场设计比较**：用统一鲁棒框架回答「HM 还是 OBZ」这个现实政策问题，结论有实操意义
4. **可计算性**：C&CG 处理大规模 min-max-min，且能识别最坏联合场景

## 5. 与已有方法的区别

| 维度 | 传统鲁棒出清 | 本文 |
|------|------------|------|
| 频率安全 | 多被忽略 | 显式惯量 + FFR 约束 |
| HVDC | 少见建模 | 允许紧急功率支援 |
| 不确定性 | 常单源(仅新能源) | 新能源+负荷+HVDC 同时 |
| 市场设计 | 单一设计 | 比较 HM vs OBZ |
| 算法 | 场景/仿射为主 | C&CG 精确识别最坏场景 |

## 6. 为什么值得关注

这篇把「频率安全」和「鲁棒优化」两个我关心的点合在一起，而且用了一个非常干净、可复现的 C&CG 框架。对我做市场出清/UC + 鲁棒优化的研究，它是很好的方法论参照：尤其是「把频率类安全约束写成鲁棒约束、用 C&CG 求解」这个范式，可以直接迁移到含储能/惯量约束的 UC 或 VPP 竞价问题上。OBZ vs HM 的结论对理解海上风电并网的市场设计也有启发。

## 7. 待思考的问题

- 惯量约束在鲁棒框架里是线性的，但**频率最低点（Nadir）约束本质是非线性的**，作者用的是简化线性形式还是完整频率响应模型？精度损失多大？
- C&CG 在「新能源+负荷+HVDC」三维联合不确定性下，最坏场景的识别会不会过于保守（over-conservative），导致备用成本虚高？
- HVDC 紧急支援假设换流站「有 headroom」，但最坏场景里换流站本身就在跳闸，这个假设是否自洽？
- 能否把「OBZ 让阻塞在日前可见」这个洞见，迁移到分布式资源/配网的竞价区划分（如 DLMP、动态分区）研究中？
