# SPECTRA: State-Space Exogenous Context and Temporal-Frequency Resolution Architecture for Probabilistic Energy Forecasting

## 1. 解决了什么问题（1-2句话）

能源预测越来越难——风光间歇性、柔性负荷波动、电力市场价格跳跃，而且你需要的不是一个"大概会是多少"，而是一个**可信的概率分布**。现有方法把多尺度分解、外生变量对齐、概率输出当成三步独立操作来做，割裂了确定性趋势和不确定波动之间的关系。SPECTRA 要解决的是：**如何在统一框架里同时建模能源序列的多尺度结构、外部影响因素和不确定性分布**。

---

## 2. 核心方法解读（通俗版）

想象你在预测明天的气温。

- 你知道夏天比冬天热（**趋势/周期性**决定基线）
- 但具体明天热不热还取决于会不会下雨、有没有冷空气南下（**外生变量**）
- 而且你需要的不只是"大概 35°C"，而是"80% 概率在 33-37°C 之间"（**概率区间**）

现有方法的做法是把这些步骤串起来：先分解序列 → 再加外部变量 → 最后估计分布。问题是：**分解步骤不知道后续要加什么外部变量，概率估计也不知道前面的分解有没有把不确定性信息丢掉**。

SPECTRA 的核心设计理念叫「**确定性-随机性分离**」(deterministic-stochastic separation)：

- **确定性流 (Deterministic Stream)**：负责捕捉趋势和周期性——这部分决定了预测的"基线轨迹"
- **随机性流 (Residual Stream)**：负责捕捉高频残差和外部扰动——这部分决定了预测分布的"宽度和不对称性"
- **两条流独立建模，但在关键节点交汇**：外生变量（温度、电价、日历等）会同时馈入两条流，确保每个变量对确定性和不确定性的贡献都被正确建模

背后的序列建模引擎是**多分辨率频谱-时间状态空间模型 (Mamba-based)**——这比 Transformer 的注意力机制高效得多（线性复杂度 vs 平方复杂度），对能源数据这种"长序列但信息密度不均"的场景很友好。

## 3. 算法/模型框架说明

```
输入: 历史能源序列 + 外生变量 (天气/日历/市场)

        ┌──────────────────────────────┐
        │   自适应时频分解模块          │
        │   (Adaptive Decomposition)   │
        └──────┬───────────┬───────────┘
               ↓                     ↓
    ┌──────────────────┐  ┌──────────────────┐
    │ 确定性流          │  │ 随机性流          │
    │ Deterministic     │  │ Residual Stream  │
    │ Stream            │  │                  │
    │                   │  │                  │
    │ 多分辨率频谱-时间  │  │ 高频残差建模     │
    │ 状态空间模型       │  │ + 外生扰动       │
    │ (Spectral Mamba)  │  │                  │
    └───────┬───────────┘  └───────┬──────────┘
            │                      │
            │  ┌──────────────────┐ │
            └──► 外生上下文对齐   ◄─┘
               │ (Exogenous        │
               │  Cross-Attention) │
               └────────┬─────────┘
                        ↓
            ┌──────────────────────┐
            │ 有序分位数边界估计    │
            │ (Ordered Quantile    │
            │  Boundary Estimation)│
            └──────────┬───────────┘
                       ↓
输出: 预测分布 (分位数区间 + 中位数)
```

**设计亮点**：
1. **确定性-随机性流分离**：两条流共享外生上下文但不互相污染
2. **频谱-时间多分辨率建模**：同时从频域和时域捕捉多尺度模式
3. **端到端分位数估计**：不是后处理加参数假设，而是直接学出有序分位数边界

---

## 4. 关键创新点

1. **确定性-随机性分离作为架构设计原则**：不是算法层面的技巧，而是上升到架构哲学的层面——这是被实验验证有效的设计范式
2. **统一多任务框架**：一套架构同时适用于负荷、电价、光伏、风电四种预测任务，在 18 个设定中 14 个取得最佳 CRPS（连续分级概率评分）
3. **Mamba 状态空间模型在能源预测的首次系统应用**：比 Transformer 更适配长序列能源数据
4. **外生变量分量级对齐**：不同频率分量收到不同权重的外部信息，而非一刀切

## 5. 与已有方法的区别

| 方法 | 关键区别 |
|------|----------|
| Autoformer / PatchTST | Transformer 基座，平方复杂度，无概率输出 |
| Transformer + 分位数回归 | 概率输出，但没有分解和双流架构 |
| Wavelet + ARIMA | 分解 + 传统统计，缺乏深度表示能力 |
| TADNet | 有概率输出和分解，但无确定性-随机性分离 |

SPECTRA 的核心理念——**先把确定性和不确定性分开建模，再在关键点融合**——是现有方法中少见的。

---

## 6. 为什么值得关注

- **通用性强**：一套架构覆盖负荷/电价/风光四大预测任务，代码开源、论文投的 IEEE Trans. Power Systems——后续很可能成为能源预测的新基准
- **对电力市场研究的直接价值**：电价概率预测是市场参与者做风险和收益评估的基础，CRPS 降低 5.74% 在交易决策中有实际意义
- **与 RL/优化方法天然互补**：SPECTRA 可以作为 DRL 能源管理的状态输入（类似 Forecast-Assisted PPO 的思路但预测质量更高），也可以为随机优化提供场景生成
- **国产力量**：中科院 + 国电投背景，且代码已开源

## 7. 待思考的问题

1. 确定性流和随机性流的分离边界是固定的还是可以通过数据自适应？什么情况下"分离"反而有害？
2. Mamba 在能源数据上的长程依赖捕捉能力是否真的优于 Transformer？需要更严谨的对比实验
3. 预测精度提升 5.74% 的 CRPS 在实际经济决策（市场竞价、储能调度）中能转化为多少收益？
4. 框架依赖于高质量外生变量——在实际系统中，天气预测不准、市场信息延迟等问题怎么影响概率预测的质量？
5. 能否在架构中直接加入物理约束（如光伏出力上限 = 辐照度 × 装机容量），让预测更物理一致？
