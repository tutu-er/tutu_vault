# 用最小风险训练增强小语言模型生成停电报告

- 论文：Enhancing Small Language Models for Power Outage Report Generation via Minimum Risk Training
- 作者：Hung Phan D 等
- 来源：arXiv:2609.27197（2026-09-23）
- 链接：https://arxiv.org/abs/2609.27197

## 1. 解决了什么问题

要把异构的停电报告转成符合 CIM IEC 61968-3 标准的统一 XML（ODIN 项目）。用大模型做这种"结构化文本生成"任务，传统 token 级最大似然目标效果差，本文想知道：改用**序列级的最小风险训练（MRT）**能不能大幅提升小模型在这种领域结构化生成上的准确率。

## 2. 核心方法解读（师兄口吻）

一句话：别再用"逐 token 最大似然"训练了，改成"直接对着整段输出的评价指标去优化"，让小模型学会照着标准生成结构化结果。

具体是这样：MRT 最早是 Shen et al. (2016) 给神经机器翻译提的，核心思想是从模型采样一批候选输出，按某个序列级指标（如 BLEU/准确率）算风险，再梯度下降最小化期望风险，从而直接优化最终评价指标。本文把这个思路搬到停电报告生成上：用 Qwen2.5-7B-Instruct 作底座，用 MRT 优化，把异构报告统一成 ODIN 的 CIM IEC 61968-3 标准 XML。

## 3. 算法/模型框架

- 底座模型：Qwen2.5-7B-Instruct（小模型，7B）；
- 训练目标：**MRT（Minimum Risk Training）**，采样候选 → 按序列级指标算风险 → 最小化期望风险；
- 任务：停电报告生成，输出 CIM IEC 61968-3 标准 XML；
- 数据：ODIN（Outage Data Initiative Nationwide）异构报告。

## 4. 关键创新点

1. 把"十年前的 MRT"重新用到现代语言模型上，验证其在领域结构化生成上的价值；
2. 面向 ODIN + CIM 标准做落地，结果显著：整体准确率从 16.20% 提升到 68.95%；
3. 证明序列级风险优化对"格式严格、可自动评测"的结构化生成任务尤其有效。

## 5. 与已有方法的区别

主流微调用 SFT/RLHF 或 token 级 MLE，间接优化最终指标；MRT 直接优化序列级指标。相比大模型 + 复杂提示，本文用 7B 小模型 + MRT 就拿到大幅提升，部署轻、成本低。

## 6. 为什么值得关注

对我做"LLM + 能源数据"方向有直接价值：电力行业有大量"非结构化报告 → 标准化结构化数据"的需求（停电、工单、调度指令等）。MRT 这种"对着可自动评测的序列指标直接优化"的思路，很适合这些格式严格、有明确标准的任务，且不依赖超大模型。

## 7. 待思考的问题

- 准确率 68.95% 是否已满足生产要求？错在哪里（字段级错误分布）？
- MRT 的风险函数/采样策略如何针对 XML 这种树状结构设计得更好？
- 能否把 MRT 与约束解码结合，进一步保证输出 schema 合法？
